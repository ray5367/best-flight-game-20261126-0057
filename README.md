Coral Run — a chase-view island-hopping flight game: fly a prop plane through 8 rings, pass 3 beacons over the archipelago, then bring her home for a touchdown on the runway. Throttle and turn discipline, fuel that runs down, stalls that drop the nose, and landings that read as what happened. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — arrows fly, W/S work the throttle, the mouse steers, P pauses, M mutes, R restarts.
